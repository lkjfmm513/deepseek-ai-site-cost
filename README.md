## 两种情况，建议绕开云端

数据绝对不能出内网的，和已经有能跑模型 GPU 的，走云端反而绕路。

**本地部署（Ollama + AnythingLLM）**：全开源，从前端框架到模型都可控，所有数据和计算留在本地网络。DeepSeek 本身提供开源商用授权，可免费用于微调、量化及衍生开发，自己折腾没有授权风险。技巧上，用 4 位量化版本（比如 deepseek-r1:7b-q4_0）能明显压低内存占用；模型选择上，R1 系列蒸馏模型在同等参数量下效果更好，其中 32B 在效果和落地成本之间平衡较好——前提是你的卡带得动。

**免费边缘部署（腾讯云 EdgeOne Pages）**：不需要任何服务器，在 Pages 控制台选 DeepSeek-R1 for Edge 模板，授权 Gitee 后一键创建，部署完就能流式对话，全程免费。但它有个容易被忽略的限制：默认分配的访问域名只有 3 小时时效，想长期使用必须绑定自定义域名，而自定义域名必须是已备案域名。域名要买、备案要等，“零成本”到这一步就结束了。它适合短期演示和活动页，不适合当长期站点养。

一句话判断：要长期挂站、要知识库和权限，选云端官方方案；数据不出门、设备现成，选本地。
